# History — the original gamification-era specs

These three files are the **original v0.1.0 product specs**, written before the 2026-06-22 pivot
away from gamification toward the calm "rear-view mirror" UsageOS is now. They describe a different
product — a gamified dashboard with a "stats screen" and a "Boss Fight" — and are **superseded** by
[`context/vision.md`](../vision.md). They're kept verbatim, not deleted: the pivot is part of the
project's story, and the decision log ([`decisions.md`](../decisions.md)) reasons from them.

- **`00-PRD-MVP.md`** — the original MVP product requirements (gamified dashboard).
- **`01-TECH-CONTEXT.md`** — the original technical context.
- **`02-FUTURE-IDEAS.md`** — early future ideas, including the cut gamification mechanics.

For what UsageOS actually is today, start at [`CLAUDE.md`](../../CLAUDE.md) → [`context/vision.md`](../vision.md).
