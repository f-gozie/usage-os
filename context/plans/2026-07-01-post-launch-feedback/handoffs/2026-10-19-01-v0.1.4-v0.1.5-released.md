## 5. Gotchas confirmed this session

- `gh pr merge --merge` worked here, for both PRs.
- The preview pane loads local HTML as a `data:` snapshot, so a board's relative
  `<script src>` doesn't load. Serve `design/` locally to check it, or open it from Finder.
- `prettier --write` reformats whole files in this repo, which isn't prettier-formatted. Don't
  run it.
- macOS has no `timeout` command. Run long `codex exec` calls in the background instead.
- The on-device model's context is 4,096 tokens; a runaway generation can overflow it.
